# SESSION terms

SESSION combines tasks, focus sessions, music, and provider-reported allowances in a desktop companion.

## Language

**Provider allowance**: The amount of plan usage a provider reports for an authenticated account. Local activity time and conversation context usage are not provider allowances.

**Quota window**: A provider-defined allowance period, such as a session window or weekly window. Different windows remain distinct even when they belong to the same account.

**Usage reading**: A timestamped observation supplied by a provider's documented interface. An unchanged local cache is not a new reading.

**Gemini usage**: The Gemini allowance reported through Antigravity for this product. Antigravity's partner-model allowances are separate from Claude Code subscription allowances.
